这里是「一个小糖人」的第一篇文章。

## 为什么要有这个博客

有些想法放在脑子里会慢慢淡掉，写在社交平台上又太吵。所以想要一块安静的地方，把想留下的东西放好，仅此而已。

## 会写些什么

大概会有这几类：

- **技术笔记** —— 踩过的坑、想明白的原理
- **读书与想法** —— 看到什么觉得有意思的东西
- **日常** —— 一些零碎的记录

## 怎么写新文章

在项目目录下执行：

```bash
hexo new "文章标题"
```

然后在 `source/_posts/` 里编辑生成的 Markdown 文件，写完推送即可。剩下的事情 GitHub 会自动完成。

就这些。开始吧。
